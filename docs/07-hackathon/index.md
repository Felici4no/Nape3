# Hackathon

## Event

Crypto World's Fair 2026.

## Hackathon objective

Build a narrow, demonstrable product that proves the comparison thesis.

## Demo thesis

> One search across fragmented delivery markets.

## Demo flow

1. Show the same purchase intent across multiple delivery sources.
2. Show that source offers have different names, prices, fees, and promotions.
3. Submit the same intent to Nape3.
4. Normalize the offers.
5. Show the effective-price comparison.
6. Explain why the selected offers are considered comparable.

## Scope lock

For the hackathon, Nape3 is not:

- a generic AI shopping assistant;
- a procurement agent;
- an autonomous payment agent;
- a complete delivery marketplace.

## Success criteria

The demo should prove that Nape3 can:

- ingest offers from more than one source;
- normalize a narrow category reliably;
- compute comparable effective prices;
- return a useful result faster than manual cross-app comparison.
