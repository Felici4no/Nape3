# User

## Primary user

A consumer who already uses more than one delivery platform and wants to minimize the effort required to compare a routine purchase.

## Job to be done

> When I know what I want to order, help me compare equivalent offers across delivery platforms so I do not need to repeat the same search manually.

## Initial journey

1. Express a purchase intent.
2. Nape3 structures the request.
3. Multiple offers are retrieved or ingested.
4. Offers are normalized.
5. Effective prices are calculated.
6. Comparable options are presented.
7. The user chooses where to continue the purchase.

## MVP decision

Nape3 does not execute purchases autonomously in the initial version.

The first objective is trustworthy comparison.
