# ADR-002 — Comparison before agency

## Status

Accepted.

## Context

The project could evolve toward autonomous shopping, negotiation, delegated wallets, and agentic payments.

Those features create complexity before the core comparison problem has been validated.

## Decision

Build trustworthy cross-platform comparison before autonomous negotiation or purchase execution.

## Consequences

The MVP prioritizes:

- source ingestion;
- normalization;
- effective price;
- comparison;
- explainability.

Agent execution remains a later layer.
